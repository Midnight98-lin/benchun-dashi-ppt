# 素材与包装保真

先读当前项目可用的正式包装与品牌资产说明，缺少私有仓库时由用户提供本次真实资产，停止猜测包装。公开来源说明见 `source-manifest.json`，其中不包含本机私有路径。仓库内场景图可用于版式样张，不等于提供完整包装设计源文件；证据占位图不能作为产品背书。

## 产品二次渲染流程

1. 建立 SKU清单：产品名、规格、容器类型、版号、源路径及hash。用户要求家族合影时逐一确认100g、30g、罐/管/盒构成。
2. 依据版面构图先设计环境、机位、尺度、文字安全区、主光和接触面。
3. AI可生成无文字、无虚构包装的自然/实验台背景和非品牌道具。产品包装是不可重画的独立保真层。遵守 imagegen 当前规则；需要对实物图合成/编辑时明确锁定原包装，不能以“看起来像”为验收条件。
4. 使用真实包装视图/对应设计源作透视、材质和环境融合：接触阴影、反射、遮挡、景深、统一色温。不得仅将透明PNG放上背景；若生成工具改坏标签，回退保真分层合成，不接受近似版。
5. 并排200%检查 Logo、产品名、净含量、文字、比例、盖体、瓶底/封尾、盒型。禁止拿100g缩小冒充30g。缺少角度时使用可验证角度或正式3D/平面资产，不能自由补画。
6. 将最终场景作为 `kind: product-scene` 引用，附 `sourceAssets`、`sku` 与真实人工核验后的 `packagingVerified: true`。此布尔不是自动检测证书；没有目视核验不可填写true。

## 其它图片

云南森林、苔藓、蕨叶、石材、水、自然光、真实原料；色温和空间与文字相融。专业表达优先原生可编辑图形，不用生图乱画有事实含义的分子结构。成分原料图不得暗示未证实的配方含量。

图表只用源数据；真实证据设 `kind: evidence` 并记录实际报告/证书路径。只允许裁白边、旋正、可读性处理；不改变任何证据文字。AI图不能作为证据。一个场景不在相邻正文页重复滥用。

## 生图简报骨架

画面用途、横版比例、场景/原料、实体尺度、光线、色温、文字安全区、环境融合；不生成标题文字、页码、Logo或证书。涉及包装附精确原资产并锁定。按 task 的 ImageGen输出管理规则保存，不把未确认生成图复制进正式资产仓库。
