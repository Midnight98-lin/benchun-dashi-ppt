# 交付自检表（复制到任务目录填写）

记录任务目录、检查日期、运行时/浏览器与所检 scene 修订号；每项标记通过、失败或未执行，并保留产物/错误依据。下列清单不是既有测试通过声明。

必读 [双技能终审](dual-review.md)。在任务目录另存逐页 `dual-review.md`；两套技能对每一页均有实际画面依据，所有缺陷解决后才能放行。不适用项注明理由；未执行视觉检查不是通过。HTML 通过不替代最终 PPTX / PDF 渲染通过。

## 内容、品牌与视觉

- [ ] 使用当次确认源稿，未改动原件；所有原文、标点、单位、表格和脚注已映射。
- [ ] 原文比对通过；图片内文字/公式/层级另行复核，未把章节逻辑做成固定规范。
- [ ] 大白话标题/专业解释仍维持原稿的层级。
- [ ] 每页全文可见，无截断、溢出、遮挡、线压字；非自动缩字。
- [ ] TV正文足够大；页码不抢标题，目录与实际页码一致。
- [ ] 深浅节奏自然，无连续三页相同三卡/大框剪影。
- [ ] 配图与当前页相关，图文是完整构图而不是左右硬贴。
- [ ] 产品SKU及30g/100g/盒体逐一对应正式资产；已200%并排核验。
- [ ] 没有AI虚构包装/文字、缩小包装冒充另一规格、假证书/检测报告。
- [ ] 数值、单位、研究条件保持原文；图表/表格为可编辑对象。
- [ ] 用户在浏览器授权的文字/数据修订已单独记录；原始锁字、goal、源文件和素材来源仍保留，没有把编辑能力当成助手改写授权。
- [ ] Taste终审记录：构图、节奏、材质、图片语义。
- [ ] Impeccable终审记录：字阶、间距、对齐、可读性。

## HTML 编辑、保存与恢复

- [ ] 默认 HTML 演示与本地编辑入口可用；若仅交 PPTX，已记录用户的明确格式要求。
- [ ] 文字、字体、位置尺寸、图片、表格单元格及图表分类/数值分别实际编辑，结果可见且没有丢失来源信息。
- [ ] 在线自动保存与手动保存均实际成功，刷新后各类修改仍在；记录保存修订号。
- [ ] 多标签页旧修订保存被阻止，没有静默覆盖较新的 scene；失败/冲突状态未被误报为已保存。
- [ ] 离线 HTML 可打开、编辑、演示；下载后重开保留上述修改及嵌入图片，明确未下载不能视为写回原文件。
- [ ] 下载的已编辑 HTML 成功导入全新目录，scene 内容保留；已有目录未被覆盖，原 HTML、goal、源稿与原始素材未改变。

## 导出与最终文件

- [ ] HTML 下载、PPTX / PDF 从同一已保存 scene 的修订快照生成；导出未重跑旧 goal 或读取旧工作簿覆盖人工修改。
- [ ] 对照 HTML 与导出文件，文字、字体、几何、图片、表格和图表修改均可追溯到该修订；导出期间的新修改不会混入旧任务。
- [ ] PPTX 已执行强制 `finalize.mjs` 终检，包结构/字体/几何/再导入检查完成，并逐页实际渲染目视检查。
- [ ] PPTX 的文字、图形、表格及图表为原生可编辑对象，不是整页截图；实际核对图表数据/嵌入工作簿与表格单元格。
- [ ] PDF 每页 16:9、无编辑器界面，分页/图表/图片/字体正常，逐页渲染检查；交代其为静态、不可编辑格式。
- [ ] HTML 与 PPTX 的字体、图表和图片组合差异已检查并修复或明确披露；未把导出成功当成视觉与编辑保真通过。
- [ ] 输出格式、附件路径可用；所有未解决问题如实说明，不声称检查过未打开的文件。
- [ ] 保存方式、本地服务关闭后的限制和离线 PPTX 需本地服务已告知；未把候选稿或技能更新自动归档为正式项目资产。
