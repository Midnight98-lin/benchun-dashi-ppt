# 对象、底色与文字样式专项验收

本清单补充 `qa-checklist.md`，不替代正文、SKU、品牌与逐页终审。使用隔离任务副本，记录脚本/浏览器版本、字体安装环境、scene 修订、最终文件及证据路径。每项标记通过、失败、未执行或本次不适用；未勾选不是通过，功能说明不是测试报告。

## 编辑与往返

- [ ] 当前页底色可修改，仅影响该页；撤销/重做可恢复，保存刷新与重新导入后颜色仍正确。
- [ ] 新增文字与矩形形状可选中、改字/改色、移动和改尺寸，不替换既有内容；界面不再重复提供“色块”入口。
- [ ] 插入 PNG、JPEG、WebP 图片后形成新的图片对象并位于最上层，原有图片保持不变；文件名、来源标记、原始宽高比、适配方式、位置尺寸和图层顺序保存重开后一致。拒绝非图片及超过 15 MB 的文件。
- [ ] 六类 `shape` 分别测试：矩形、圆角矩形、椭圆、三角形、右箭头、水平线；不把横线测试当成任意方向线或旋转测试。
- [ ] 填充颜色、无填充、描边颜色、无描边、描边粗细及适用圆角实际修改；透明处正确透出后方内容，重开后不变成默认实色。
- [ ] 原有 `rect` 保持兼容；只在修改描边/无填充的指定对象上转为 `shape`，位置、尺寸、圆角与层级不变，未批量转换旧稿。
- [ ] 新增、复制、删除、前移/后移和置顶/置底逐项核对对象数量与遮挡关系；撤销和重做能够恢复相应操作，没有同时影响其它对象。
- [ ] 字体菜单的六种字体分别测试；记录当前机器实际安装情况。修改整段文字的加粗、斜体、下划线及其组合后，原文、字号、颜色和对齐仍正确。
- [ ] 文字、形状和图片均显示同一套“自由变形”控件；表格和图表不错误显示。角度滑杆与数值输入同步，-180°至180°边界、左右转90°、水平/垂直翻转、组合变形和一键重置均实际生效。
- [ ] 旋转与翻转不改变对象`x/y/w/h`、内容、图片源、形状几何和图层；选中框跟随旋转，拖动位置后变形保持。撤销/重做、保存刷新、离线HTML和新目录导入后仍一致。
- [ ] 上述修改完成在线自动保存和手动保存、刷新、HTML 下载、离线“保存 HTML”后重开，以及导入全新目录；对象数量、底色、图层顺序和全部样式与保存稿一致。
- [ ] 新字段参与旧修订冲突保护；过期页面不能静默覆盖最新对象或样式。原 goal、原稿及源资产不变，已有目录导入仍被拒绝。

## 导出与检查边界

- [ ] PPTX / PDF 从同一已保存 scene 修订导出，导出后点击完成链接实际下载；没有重建旧 goal 丢失新增对象。
- [ ] PPTX 通过强制 finalizer；服务带入同一快照的 `--scene`，字体集合包含实际使用的字体，而不是固定只检查 Microsoft YaHei。
- [ ] PPTX 中新增文字与六类图形为原生可编辑对象，插入图片为独立图片对象；核对填充、无填充、描边、描边粗细、圆角、底色、图片比例、旋转、水平/垂直翻转与图层顺序，不以整页截图替代对象。
- [ ] PPTX 中字体、字号、加粗、斜体和下划线属性保留；同时渲染查看，不能只凭 OOXML 字段存在声称视觉一致。原有图表、表格及数据未退化。
- [ ] PDF 为静态逐页打印结果；实际查看底色、透明形状、描边、插入图片、文字斜体/下划线、旋转/翻转、字体回退、换行和遮挡，无编辑器操作栏。
- [ ] 在移动设备或另一台电脑的检查如未执行，明确标注；不承诺字体自动安装、字体嵌入、跨设备绝对一致或未实现的透视扭曲/逐点变形/斜切/3D旋转/逐字富文本/任意图形/新增页面。
- [ ] 最终稿符合原文与品牌保护要求；没有把提供复制/删除功能推定为删除原文、证据或正式资产的授权，也没有把测试副本认定为正式归档。
# 确认版编辑器补充验收（2026-09-09）

- 右侧样式／排列／页面切换、自由变换浮层开关与 Escape、减少动态效果模式均保持可用。
- 圆角矩形的滑块与数值输入同步；0、正常值、短边一半和非法值均检查，拒绝越界值。
- 半径修改保存重载后保留；旧 rect 圆角对象改为 0 后仍可重新调整圆角。
- 圆角控件在桌面面板中清晰可见；窄屏不横向溢出。导出同一 scene 后核验圆角与对象可编辑性，不能仅凭参数存在认定视觉无差异。
