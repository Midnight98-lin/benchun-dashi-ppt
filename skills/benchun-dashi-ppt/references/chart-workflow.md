# Lieflat Charts 与本纯 PPT 的衔接

此协议用于制作或优化数据图表，连接图表制作与已有 PPT 工作流，不改变课件业务内容、整套品牌或编辑器功能。上游源文件保留原样；实际模板规则以随包版本为准。

## 入口与许可

- 相对于本纯技能根：`chart-skills/lieflat-charts/SKILL.md`、`LICENSE`、`catalog.md`、`mono-tokens.js`、`color-presets.js`、`templates/`。只有用户明确要求独立报告时才读取 `report-catalog.md`；PPT 数据页仍是图表模式。
- 已随包提供完整依赖，无需本纯私有仓库或另装图表技能。将上游文档中的 skill 根路径解析为此目录。更新时先比较规则／许可，验证快照，不混用新目录和旧模板。
- Lieflat Charts 使用 PolyForm Noncommercial 1.0.0。先记录用途属于许可覆盖的非商业用途，或有适用的额外许可；安装、用户要求制作、本包可下载和署名均不等于商业许可。不得把品牌营销、经营或招商用途默认标为非商业。未有依据时保全数据和原稿，完成页面规划，列明图表制作等待许可，不使用其模板制作商业成品。

## 数据先于模板

主 AI 锁定数据；word_agent 核对标题、单位、图例、期间、注释和来源；pic_agent 依据锁定数据制作；word_agent 复核图中文字和读数；主 AI 终审。无子代理时依次执行并记为单 AI。数字、坐标轴、形状和比例不得交给生图模型猜绘。

保存数据源及授权修订，记录统计粒度、分母、缺失值、期间、版本与来源。缺失／未报告不当零；试验原料与产品效果不混同；用户原文和已确认结论不因模板标题规则被改写。测试才可使用明确标注的模拟数据，不把演示数据或模板原结论带入成品。

**百分比与人数的适配纠正**：仅有百分比时，单位分解须写“1点＝1个百分点”，不能把点写成“人”或推定样本人数。上游关于不足100时“另外N人被四舍五入吃掉了”的示例不适用于这种数据。先区分原始比例合计、未报告份额和实际取整差额，原合计不足100不得直接归因于舍入，更不能把余量擅自补成某类。小数比例优先选择可准确承载的连续编码模板；若使用点阵近似，保留原值并注明精度／取整规则，不凑点或修改原数据。此纠正写在适配层，上游快照不改动。

## 选型与品牌适配

1. 按随包 SKILL 当前主力／后备规则比较至少三个可行候选，不足三个时列出全部；先比较 Lupi Editorial 和 Basics，Glance 只在符合上游条件时使用。特定数据形状例外按上游规则；地图仅在用户明确要求时启用。
2. 锁定图型编号、gallery 路径和卡标题，实际读取对应结构及渲染代码，再替换任务数据。不能把模板名称写进提示词就当调用成功；不回退到默认样式、不拼造混合图型。
3. 按本纯 `assets/tokens.json` 和品牌规则映射一套 custom 色板，所有图共享角色；只派生必要明暗，不借用其它预设色。保持颜色语义和对比度。中文使用已核验的品牌字体，检查回退与换行；不因 Inter 或默认 Mono 改变母版。记录这种 PPT 适配，不能说上游原生排版未经适配就已经遵守。
4. 保留核心结构和数据契约：柱从零开始、面积按平方根换算半径、坐标／比例／排序可核验。标题、单位、图例、来源保留在图内或页面清晰对应处。按目标画布检查字号和线宽，不把 gallery 微小标签直接作为投影字号；太密时分页，不能删掉锁定数据／文字。

## HTML、PPTX 与 PDF

先生成独立图表 HTML 和数据快照。交互图保留 HTML 供查看；PPT／PDF 必须显露必要读数，不能依赖 hover。捕获静态版前完成字体／CDN加载、reveal和动画，滚入目标容器并确认内容实际绘制，不捕获空图或中间帧。离线交付验证依赖已内联或说明网络要求。

本包只增加技能资源与制作协议，**没有自动把 Lieflat HTML 导入 scene 或转换成任意原生图表的功能**。不要向 `goal.json` 填入未支持的图表类型。按实际能力选择：

| 目标 | 实际处理与限制 |
| --- | --- |
| 原生可编辑 PPTX 图表 | 能保留模板编码与可读性时制作平台支持的原生对象，核对嵌入数据及最终渲染。不能用默认样式替代所选模板后仍声称模板保真。 |
| 复杂 SVG／Canvas 模板 | 保留 HTML 和数据源。静态嵌入采用实际渲染的 SVG 或足够分辨率的 PNG，注明图片对象。现有编辑器插图只接受 PNG/JPEG/WebP，SVG须用合适导出工具处理或栅格化，不承诺直接插入／逐元素编辑。 |
| 用户要求全部图表原生可编辑 | 先核实转换能力。不能保真的复杂图须取得用户对简化图型或静态嵌入的决定，不能静默换图片或用外部数据文件冒充原生编辑。 |
| PDF | 静态图从已核验画面导出，逐页检查读数、中文、线宽、边缘和清晰度。 |

原生对象用现有 scene 支持类型承载；静态嵌入也纳入已保存修订。图表 HTML、数据源、来源和嵌入文件哈希留在任务目录，记录图表→页码／scene对象／格式的对应。浏览器改数据时更新有效快照和派生产物，不重跑旧 goal 覆盖保存稿。非图表页沿用原工作流。

## 审查记录与放行

保存 `chart-review.md`：用途和许可依据（不复制私密合同）、源数据版本／哈希与口径、候选及理由、图型ID／gallery／卡标题、实际代码位置、色板／字体、计算／比例、页码和对象、源HTML及导出截图、原生或静态编辑能力、结果与未解决项。无图表时在双审查记录标 N/A。

先复核数值、单位、期间、分母、总计、零点、尺度、面积、颜色含义和结论，再进入同修订 Taste 逐页构图与 Impeccable 逐页可读性审查。各格式分别核验，标记通过／失败／未执行。脚本成功不代替看图，HTML通过不替代PPTX通过；包中存在图表技能不等于任何成品已经通过审查。
